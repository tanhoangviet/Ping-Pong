# Friendly 3D Ping Pong

A nostalgic, friendly 2018-style browser ping pong game for two local players. The game uses a responsive HTML canvas, bright pastel neon colors, chunky paddles, a faux-3D environment, a glass mini-map HUD, glow trails, scoring, pause support, mobile touch controls, landscape optimizations, and a first-to-7 win condition.

## Controls

- Player 1: `W` / `S`
- Player 2: `Arrow Up` / `Arrow Down`
- Pause: `Space`
- Mobile: on-screen touch pads for both players
- Best mobile view: landscape orientation

## Run Locally

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```
