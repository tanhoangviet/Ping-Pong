# Friendly 3D Ping Pong

A nostalgic, friendly 2018-style browser ping pong game for two local players. The game uses a responsive HTML canvas, bright pastel neon colors, chunky paddles, a faux-3D court, glow trails, scoring, pause support, and a first-to-7 win condition.

## Controls

- Player 1: `W` / `S`
- Player 2: `Arrow Up` / `Arrow Down`
- Pause: `Space`

## Run Locally

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```
